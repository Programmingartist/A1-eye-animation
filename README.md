# 双圆屏眼睛动画

双击 `index.html`，用 Edge 或 Chrome 打开即可。无需联网，无第三方运行依赖。

- 每眼独立 360×360 像素，圆外纯黑；双眼合并为 720×360，无间距、无控制面板。
- 参考图八种表情：爱心眼、开心笑眼、生气、太热了、困倦、超级开心、委屈流泪、呆萌对眼。
- 新增“森林精灵”玻璃眼样式及六种森林动作，并保留原有八种表情和四种基础动作，共十八种。
- 森林精灵样式按玻璃外壳、深色内景、远近植物、花朵、蝴蝶和发光微粒分层绘制。蝴蝶持续扇动并轻微悬浮，花草随风摆动；视线转动时各层以不同幅度移动，形成球体内部的纵深视差。
- 森林精灵提供待机、自然眨眼、左右观察、惊喜聚焦、困倦眯眼和瞳孔震颤六种常用动作；每种动作沿用同一套玻璃与景物图层，可继续使用指针跟随和手动眨眼。
- 森林精灵的玻璃壳、花朵和蝴蝶图层从用户参考图中提取，展开关键帧保持原图轮廓与光影；`make_forest_assets.py` 可从项目内的 `assets/forest-reference.png` 重新生成全部分层素材及可供本地页面安全导出的 `forest-assets.js`。
- 白色眼白、中性灰色眼皮、蓝青色透亮虹膜和右上多点高光；灰色眼皮与纯黑背景区分。
- 爱心轻轻跳动、火焰摆动、彩纸飘落、泪水起伏；对眼时两只眼珠向鼻侧聚拢。所有装饰都裁切在圆屏内部，没有机身或鼻子。
- 空格暂停，B 眨眼，H 隐藏或显示面板。全屏后按 Esc 退出。
- 支持指针跟随，以及蓝青、琥珀、紫罗兰虹膜。
- 视线按球面转向投影：虹膜产生透视压缩，深处的瞳孔位移更小，内部反光与表面高光具有不同视差。保留卡通质感，不使用写实眼球模型。
- 默认进入森林精灵。把指针移到眼睛区域即可带动多层内景转动；指针离开时平滑回到自主动作。跟随有柔和收势和凝视微动，暂停会同时冻结这些动作。
- 硬件的 1.8 英寸由实际面板决定；浏览器预览不代表物理尺寸。

## 导出

选择时长（4/8/12 秒）、帧率（18/24/30/60）、布局、格式，再点击导出。所选帧率同时用于预览和导出；例如 4 秒分别生成每眼 72/96/120/240 帧，采样时间为帧号除以帧率，不重复导出结束时刻。

1. **PNG 序列帧 ZIP**：逐帧按确定时间采样，左右眼帧号严格对应。`left/00000.png`、`right/00000.png` 或 `pair/00000.png`。适合硬件转换、视频编辑、合成。PNG 无损，角落是黑色而非透明。
2. **WebM**：实时录制，ZIP 内有左右两段视频或一段并排视频。建议录制期间保持浏览器窗口在前台。实际帧率受机器负载影响；需要精确帧数时用 PNG 序列。
3. **PNG 精灵图 ZIP**：按行排列、自动分多张图，避免单张图片过大。单眼每页 8×4 帧；双眼每页 4×4 帧。最后一页有效帧数记录在清单中。
4. **当前帧**：导出当前视线和眨眼状态的 PNG。

每份 ZIP 都包含 `manifest.json`，记录尺寸、帧率、时长、布局和帧顺序。动画导出从该动作的 0 秒开始，使用固定视线轨迹，不包含鼠标输入或手动眨眼，确保左右同步并可复现。渲染轨迹周期为 12 秒；4/8 秒文件是截取，首尾不保证连续。

`examples` 中提供预生成 GIF，便于查看。GIF 只有 256 色、25 fps，细节与流畅度以实时程序或 PNG 为准。程序本身不直接导出 GIF/MP4。

## 程序接口

引入 `eyes.js` 后调用：

```js
Eyes.render(canvas, seconds, {
  mode: 'superhappy', // heart / happy / angry / hot / sleepy / superhappy / cry / cross
  // 森林动作：forest / forest-blink / forest-look / forest-surprise / forest-sleepy / forest-tremor
  // 基础动作：idle / curious / surprise / playful
  side: 0,     // 0 = left, 1 = right
  color: 'aqua' // aqua / amber / violet
});
```

Canvas 的宽高设为 360。两只眼睛使用同一个时间参数。渲染器以白色眼白、预缓存多层虹膜、瞳孔云状反光、角膜多点高光、水光、灰色上下眼皮与表情装饰分层绘制。不缩放眼球模拟眨眼。开心笑眼以睁眼微笑为主，穿插轻轻眯眼和自然眨眼；爱心表情用跳动爱心替代虹膜。视线沿柔和弧线移动，眼皮投下柔软阴影，虹膜反光随深度变化。

可选传入 `gaze: [x, y]` 控制视线（建议 x 在 ±61、y 在 ±48 内），渲染器会转换为球面转角；`lag: [x, y]` 只影响湿润反光的轻微滞后；`attention: 0..1` 控制注视时的瞳孔响应。`Eyes.optics(state)` 提供虹膜、瞳孔和高光的投影位置。预览中的弹簧跟随位于 `app.js`，导出仍使用确定的自主视线轨迹。

以用户提供的八表情参考图为主要视觉依据，结合前序 Ropet 视频。实现为程序化视觉重建，未使用品牌固件，也不是参考图的像素级复刻。参考图中的机身、鼻子与屏幕外装饰不在输出中。尚未连接实体圆屏；设备接入需要确认控制器、接口与像素格式。
